Questions fréquentes

Quel est le code promo BSTN en ce moment ?

Jusqu'au 30 novembre 2026, le code BLACK25 donne 25 % de réduction supplémentaire sur presque tout le site BSTN, y compris les articles déjà soldés, pendant la Black Week Sale.

Comment utiliser un code promo BSTN ?

Ajoutez vos articles au panier sur bstn.com, puis saisissez le code dans le champ « Code promo » avant de payer. La réduction s'affiche dans le récapitulatif de commande.

Le code BSTN fonctionne-t-il sur les nouvelles sorties ?

Pas toujours. BSTN annonce ses codes sur « presque tout » : certaines sorties récentes ou marques peuvent être exclues. Si la réduction n'apparaît pas au panier, l'article est exclu.

À quelle fréquence BSTN propose-t-il des codes promo ?

En 2026, BSTN a lancé un code presque chaque mois : SUMMER15 en mai, SPORT25 en juin, PRM25 en octobre, GHOST20 pour Halloween, SINGLE20 et SINGLE25 pour le Singles Day, WINTER20 puis BLACK25 en novembre. Cette page est mise à jour à chaque nouveau code.
